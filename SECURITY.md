# Security Policy

## Supported versions

This project is an early MVP. Only the latest default branch is currently maintained.

## Reporting a vulnerability

Please do not post exploitable security issues, credentials, personal data, or real invoice documents publicly. Contact the repository owner privately through GitHub's available contact options and include a concise description and steps to reproduce.

## Data handling

- Use synthetic or anonymised data in demos and tests.
- Do not store API keys in source code.
- Do not expose a future API publicly without authentication, rate limiting, and appropriate access controls.
- Review logs to ensure they do not leak invoice or customer details.
